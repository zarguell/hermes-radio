# Hermes Radio 📻

**Zero-LLM daily broadcast engine** — generates an audio show or text briefing from live web data. Supports hybrid mode where some segments are zero-token (SearXNG, content banks) and others use LLM reasoning.

Inspired by [u/amaksimchuk's Hermes Radio](https://www.reddit.com/r/hermesagent/comments/1tpms69/what_cron_jobs_do_you_run_with_hermes_agent_heres/) on r/hermesagent.

## Features

- **Zero-token by default** — headlines, music, tips, jokes, and quotes via API calls and content banks. No AI calls needed.
- **Hybrid mode** — mix zero-token segments with LLM-generated segments (summaries, analysis, original jokes). Per-segment configurable.
- **Dual output** — audio broadcast (TTS + FFmpeg → MP3) or text-only briefing from the same pipeline.
- **Jinja templated** — every broadcast's narration script and Telegram caption come from editable `.j2` templates.
- **Pluggable content banks** — tips, jokes, quotes rotate daily via simple text files.
- **Self-hosted** — uses your own SearXNG instance, edge-tts for speech, FFmpeg for assembly.
- **Hermes Agent cron ready** — supports both `no_agent: true` (zero-token) and full agent mode (hybrid).

## Quick Start

### Dependencies

- Python 3.11+
- [FFmpeg](https://ffmpeg.org/)
- [edge-tts](https://github.com/rany2/edge-tts)
- [SearXNG](https://docs.searxng.org/) (self-hosted)
- Jinja2, PyYAML

```bash
pip install jinja2 pyyaml edge-tts
# macOS: brew install ffmpeg
# Ubuntu/Debian: sudo apt install ffmpeg
```

### Setup

```bash
git clone https://github.com/zarguell/hermes-radio.git
cd hermes-radio
cp config.example.yaml config.yaml
# Edit config.yaml with your SearXNG URL, voice, segments, etc.

# Zero-token mode (all segments from APIs/banks):
python3 broadcast.py

# Text-only briefing:
python3 broadcast.py --mode text
```

## Configuration

See [`config.example.yaml`](config.example.yaml) for the full reference.

### Segments

The show is built from an ordered list of segments, each with its own data source:

| Source | Description | Zero-token? | Example |
|--------|-------------|-------------|---------|
| `searxng` | Fetched from your SearXNG instance | ✅ | Headlines, trending music |
| `bank` | Rotated from a content bank text file | ✅ | Tips, jokes, quotes |
| `llm` | Generated by the Hermes agent | ❌ (uses tokens) | Summaries, analysis |
| `literal` | Fixed text in the template | ✅ | Intro, outro |

Example segment config:

```yaml
segments:
  - id: headlines
    source: searxng
    params:
      query: "AI artificial intelligence {month} {year}"
      max_results: 4
      category: news

  - id: summary
    source: llm
    prompt: >
      Summarize these {n_headlines} AI headlines in 2-3 concise sentences.
      Headlines: {headlines_str}
    model_hint: "deepseek-v4-flash"

  - id: tip
    source: bank
    params:
      bank_path: ./content_banks/tips.txt
```

Each segment's `id` becomes a template variable (`{{ headlines }}`, `{{ summary }}`, etc.). LLM prompts can reference any earlier segment's data using `{variable_name}`, `{variable_name_str}` (for lists joined as text), or `{n_variable_name}` (for list lengths).

## Pipeline Steps

For hybrid mode (LLM segments enabled), the broadcast is built in three phases:

### Phase 1: Collect (zero-token, script-only)
```bash
python3 broadcast.py --step collect
```
Outputs a JSON object with all API/bank data plus pending LLM segment definitions.

### Phase 2: Process (agent, uses tokens)
The Hermes agent reads the JSON, runs each LLM segment's prompt, and writes the results back.

### Phase 3: Build (script-only)
```bash
python3 broadcast.py --step build /path/to/context.json
```
Renders templates, generates TTS, assembles audio, outputs caption + `MEDIA:` path.

For zero-token mode (all `source: searxng` / `source: bank`), the full pipeline runs in one step:
```bash
python3 broadcast.py
```

## Templates

Two Jinja2 templates in `templates/`:

| Template | Purpose | Available Variables |
|----------|---------|-------------------|
| `tts_script.txt.j2` | Spoken narration | All segment IDs, `date`, `short_date` |
| `telegram.md.j2` | Telegram caption | Same + `duration`, `mode` |

Edit these to reorder segments, change wording, or add custom sections.

## Content Banks

Text files in `content_banks/`, one item per line. `#` lines are ignored. Each day picks one item via deterministic day-of-year rotation.

- `tips.txt` — tech/sysadmin tips
- `jokes.txt` — tech/AI humor
- `quotes.txt` — engineering wisdom

## Hermes Agent Cron Integration

### Zero-token mode (no agent needed)
```yaml
# Cron job config:
# no_agent: true
# script: hermes-radio.sh (or direct path)
# schedule: "0 11 * * *"
# The script's stdout is delivered directly to Telegram
```

### Hybrid mode (with LLM segments)
```yaml
# Cron job config:
# skills: ["hermes-radio"]
# prompt: "Follow the hermes-radio skill instructions to produce today's broadcast."
# workdir: /opt/data/hermes-radio
# schedule: "0 11 * * *"
```
The skill handles the full pipeline: collect → process LLM segments → build → deliver.

## Architecture

```
broadcast.py              # Engine
├── config.yaml           # Segment definitions, API keys, voice
├── SKILL.md              # Hermes Agent skill for hybrid mode
├── templates/
│   ├── tts_script.txt.j2 # What the voice reads
│   └── telegram.md.j2    # Telegram caption
├── content_banks/        # Rotating content
│   ├── tips.txt
│   ├── jokes.txt
│   └── quotes.txt
└── output/               # Generated MP3s
```
